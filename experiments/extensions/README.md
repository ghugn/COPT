# Research Extensions

New methods belong here only after the paper reproduction is established.

The first controlled extension will compare vertex rankings under the same
decoder and search implementation:

1. random ranking;
2. degree, core-number, and triangle rankings;
3. randomly initialized COPT;
4. pretrained COPT;
5. pretrained COPT used to warm-start or order an anytime/exact solver.

External-paper methods are not part of the current implementation. Any future
use of NExCO, ASAP, diffusion, or another method must be introduced as a
separate experiment with an explicit citation and method-level ablation.
